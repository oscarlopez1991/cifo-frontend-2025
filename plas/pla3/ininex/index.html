Explanations

Internal better than External:

  • For quick testing
  • Specific styles for a unique page
  • If there's any inconvenient in not using external CSS

External better than Internal:

In most cases (or in the remaining cases), I think it's better practice to aim for more cohesion, cleanliness, and overall clarity.

Inline inconveniences

  • Hard to maintain
  • Breaks the separation between content and presentation
  • Increases HTML size unnecessarily

Interesting cases to use

Same as with the comparison between internal and external CSS: inline CSS should only be used in very specific or limited cases.
