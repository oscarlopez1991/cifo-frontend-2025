# 🎓 CIFO Frontend Development 2025 (`cifo-frontend-2025`)

> Comprehensive laboratory exercises, projects, and reference implementations developed during the **CIFO (Centres d'Innovació i Formació Ocupacional)** Frontend Development curriculum (2025).

---

## 🗺️ Curriculum Structure & Modules

The repository is organized into three progressive learning tracks:

```
cifo-frontend-2025/
├── Javascript/        # Pure modern ES6+ JavaScript & DOM APIs
├── React/             # Single Page Applications (SPA) with React
└── React Native/      # Mobile cross-platform applications
```

---

### 1. 🟡 Modern JavaScript (`/Javascript`)

Focused on modern ECMAScript standards (ES6+), asynchronous flows, DOM manipulation, and REST API consumption.

- **`CryptoDemo`** — Real-time cryptocurrency price tracker consuming public crypto APIs. Features dynamic DOM rendering, async/await data fetching, search/filter controls, and responsive UI.
- **`Practices`** — Foundational exercises covering array transformations (`map`, `filter`, `reduce`), closures, promises, event delegation, and modular JavaScript patterns.

---

### 2. ⚛️ React SPAs (`/React`)

Component-driven UI development with React, focusing on functional components, hooks, state management, and external API integration.

- **`instapicsum-pla`** — Dynamic image catalog consuming the Lorem Picsum API. Demonstrates component decomposition, custom hooks, image loading states, and grid layouts.
- **`open-trivia-pla`** — Interactive trivia quiz game powered by the Open Trivia Database API. Implements question sequencing, score calculations, category filtering, and immediate feedback states.

---

### 3. 📱 React Native Mobile (`/React Native`)

Cross-platform mobile application development for iOS and Android using React Native, native UI primitives, and device APIs.

- **`Instapicapp`** — Mobile photography feed application with native gestures, pull-to-refresh, and image caching.
- **`rick-and-morty-pla`** — Character directory powered by the Rick and Morty API. Implements `FlatList` virtualization, detail modal views, search, and species/status badges.
- **`React Native Setup`** — Environment configuration documentation, Android Studio emulator setup, and Metro bundler troubleshooting notes.
