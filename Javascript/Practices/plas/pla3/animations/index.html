CSS Animations – Learning by Doing

1. Bouncing Ball

This animation makes a circle bounce up and down infinitely. It uses the transform property along with keyframes and the animation shorthand rule.

Key concept: The translateY value controls the vertical movement. You can change it to adjust how high the ball bounces.

2. Smooth Color Transition

This square smoothly changes its background color when you hover over it. It uses the transition property.

Key concept: You can change transition-duration or transition-timing-function to control the speed and style of the animation.

3. 3D Rotation

This element rotates in 3D when you hover over it. It uses transform: rotateY and perspective to create a 3D effect.

Key concept: You can rotate on the X or Y axis, and tweak the angle for different effects.
