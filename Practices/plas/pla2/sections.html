Header section (main title)

The top section of a web page, usually containing the main title, logo, or introductory content.

Navigation section

A semantic container that defines a section of navigation links, typically used for menus:

  • Home
  • About us

Div container section

A generic container without semantic meaning, used to group content.

Section content

A semantic container is used to define and group related content into distinct sections of a document.

Footer section

A semantic container that represents the concluding section of a document or a section, typically containing information like copyright, author, related links, or contact details:
