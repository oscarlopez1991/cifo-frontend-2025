Media Queries and Color Codes Explanation

The color codes #9004, #0904, and #0094 use the 4-digit hexadecimal RGBA shorthand in CSS.

Each digit represents a component of the color:

  • 1st digit: red channel (0–F)
  • 2nd digit: green channel (0–F)
  • 3rd digit: blue channel (0–F)
  • 4th digit: alpha (opacity) level (0–F)

For example, #9004 expands to #99000044, which is a dark red with some transparency.

Yes, hexadecimal values can contain both numbers (0–9) and letters (A–F), where A to F represent values from 10 to 15. This format is used widely in web development to define color and opacity in a compact way.
